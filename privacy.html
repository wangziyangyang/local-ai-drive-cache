隐私说明

Local AI Drive Cache 仅为账号持有人恢复本人指定的模型缓存。Google 账号身份用于确认登录，Drive 只读权限用于查找和读取指定目录内的模型、校验记录及后端归档。程序不通过 Drive API 修改、删除或分享文件。

长期 OAuth 刷新凭据及客户端配置保存在用户自己的 Windows 电脑，使用当前用户的 DPAPI 加密并限制文件访问。长期刷新凭据不写入 Notebook、源码、日志或上传至 Colab。

为让 Colab 直接从 Drive 获取文件，运行时可能接收短期访问凭据并仅在内存中使用。Google 和 Colab 将按其自身政策处理这些请求。本工具不将 Google API 取得的数据出售、用于广告或用于开发者训练通用模型。

此说明站点不接收 Drive 文件或授权凭据。静态托管服务可能按其政策记录常规网站访问日志。

用户可在 Google 账号的第三方连接页面撤销权限，并在本机移除工具的加密凭据文件。撤销后，程序无法继续自动读取 Drive。模型文件与聊天功能的使用由用户自行控制。

本工具对 Google API 数据的使用遵循 Google API Services User Data Policy，包括 Limited Use 要求。功能或数据处理方式变化时应同步更新本说明。
